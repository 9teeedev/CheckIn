# เช็คอินหน้าห้อง

ระบบเช็คอินเข้าเรียนสำหรับเครื่องเดียววางหน้าห้อง นักศึกษาสแกน QR บัตรนักศึกษา หรือพิมพ์รหัส 11 หลัก

## วิธีใช้

```bash
npm run build
npm start
```

เปิด http://localhost:3000 ที่เครื่องที่วางหน้าห้อง

- **หน้าเช็คอิน (`/`)** — กล้องเปิดอัตโนมัติ ชี้ QR บัตรนักศึกษา หรือพิมพ์รหัสแล้วกดเช็คอิน เด้งสีเขียว + เสียงเมื่อสำเร็จ เหลืองเมื่อเช็คซ้ำ แดงเมื่อรหัสผิด/ไม่อยู่ในทะเบียน
- **หน้าแอดมิน (`/admin`)** — 3 แท็บ
  - **วันนี้** — รายชื่อ+จำนวนคนที่เช็คแล้ววันนี้ ลบรายการที่ผิดพลาดได้
  - **ทะเบียน** — เพิ่มนักศึกษาทีละคน หรืออัปโหลด CSV รูปแบบ `รหัส11หลัก,ชื่อ-นามสกุล` (แถวหัวตารางข้ามอัตโนมัติ)
  - **ยังไม่เช็ค** — ใครในทะเบียนยังไม่เช็ควันนี้

## กติกาที่ระบบบังคับ

- รหัสต้องอยู่ในทะเบียนถึงเช็คได้
- เช็คได้คนละ 1 ครั้งต่อวัน (ตามเวลา Asia/Bangkok) สแกนซ้ำเด้งเตือน + บอกเวลาเดิม
- QR ดึงเลข 11 หลักจากข้อความที่สแกนได้ จึงใช้กับ QR ที่มีข้อความอื่นปนได้

## ข้อมูล

เก็บใน SQLite ที่ `data/checkin.db` (สร้างอัตโนมัติ) ใช้ `node:sqlite` ในตัว Node ไม่ต้องติดตั้งอะไรเพิ่ม ต้องใช้ Node 22.5+

## หมายเหตุกล้อง

เบราว์เซอร์อนุญาตให้ใช้กล้องเฉพาะ `localhost` หรือ HTTPS ถ้าจะเปิดจากอุปกรณ์อื่นใน Wi-Fi เดียวกัน ต้องรันผ่าน HTTPS (เช่น `npx local-ssl-proxy` หรือ Caddy) หรือเปิดบนเครื่องเซิร์ฟเวอร์เอง
